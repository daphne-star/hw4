Design of the Site

Primary UI font: `DM Sans`, used for navigation, buttons, labels, product metadata, body copy, and chat text.
- Display font: `Playfair Display`, used in italic for hero emphasis and major editorial headings.

- Product names and prices: bold and prominent for quick scanning in grids and cards.
- Body copy: comfortable line height and restrained line length for readability.

## Color scheme

| Role | Color | Use |
|---|---|---|
| Cream canvas | `#f8f5ef` | Main page background |
| Warm surface | `#fbfaf7` / `#fffdfa` | Cards, modals, drawers, and forms |
| Yale navy | `#173f65` | Primary buttons and strong actions |
| Deep ink | `#17324d` | Main text and headings |
| Muted blue | `#5d83a7` / `#6e91ad` | Brand accents, labels, and links |
| Soft blue-green | `#e2eff1` / `#deeee8` | Chat headers, chips, and supporting states |
| Gentle border | `#d9e2e5` / `#e3e0d8` | Dividers, cards, and fields |
| Error rose | `#f7e8e5` with `#8d514b` text | Error and failed-action states |

## Spacing and shape language

- Use generous whitespace around major headings and page sections.
- Use compact gaps in grids, filters, chat messages, and card content.
- Use thin gentle borders and reserve soft shadows for floating cards, drawers, and modals.
- Frame black-background catalogue images on padded neutral tiles so they feel intentional rather than like dark gaps in the cream layout.

## Changes made for P10

- Made the cursor a bulldog. Bulldogs are the school mascot and this is a fun touch for the website.

- Made the chat collapsible so it doesn't get in the way of the consumer browsing.

- Made the colors of products swatches instead of text. this way it's more visual for the users.
